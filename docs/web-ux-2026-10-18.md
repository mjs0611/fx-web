## 검증

`python3 -m unittest discover -s tests -v`: 56개 통과. 월 링크 누락·중복, 최근 연도만 펼침, 월 기록의 현재 통화 표시와 회사 복귀를 추가로 확인합니다.

공개 사이트에 이미 게시된 `data/history.json`을 로컬 검토에만 사용해 719페이지를 생성했습니다. 신규 환율 API 수집은 하지 않았습니다. 719페이지의 내부 참조 11,508개에 파일·앵커 누락이 없었습니다.

Chrome/WebKit 320·390·1440px, 글자 200%, 감소된 모션, 연도 접기·월 이동·뒤로가기, 반복 그래프 전환, 계산기 오류·복구, JavaScript 없는 화면과 axe 검증 결과는 작업공간 `evidence/web-services/verification.json`에 보존합니다. 전후 픽셀은 같은 폴더의 `before/`, `after/`에 있습니다. 외부 광고·글꼴 요청은 브라우저 검증에서 차단합니다.

두 서비스 합산 46개 브라우저 흐름과 axe 12회 검사를 통과했으며 위반·페이지 실행 오류는 0개입니다. 별도의 주요 12페이지 콘솔 검사에서도 애플리케이션 콘솔 오류·로컬 HTTP 오류는 0개입니다. 의도적으로 차단한 외부 요청과 콘솔 결과는 `console.json`에 구분해 남겼습니다.

Mac 기본 WebKit 러너는 Tab 순서에서 링크를 생략합니다. Chrome에서는 첫 Tab의 본문 이동 링크를 검사하며, WebKit에서는 해당 링크에 초점을 준 뒤 Enter의 본문 초점 이동을 검사합니다. 운영 배포·원격 push·DNS·운영 데이터 쓰기는 하지 않았습니다.
